### Fixed

- **Upgrading from WoW AI fixes the bridge's file paths.** `setup.js` now points `bridge/config.json` at `Runback\Inbox.lua` and `Runback.lua` when it still named the `WoWAI` folder or `WoWAI.lua`, and the bridge reads such a config the same way. Before, the reload fallback (`/runback mode reload`) and the bulk-question reader looked at the old saved file, which the game no longer updates, and the inbox fallback was written into the moved `WoWAI` folder; the default pixel transport was not affected. The 200 `WoWAI_S###` reply-slot folders also move into `Runback-backup-YYYY-MM-DD`, so the AddOns list no longer shows them with a missing dependency.
