### Added

- **OpenCode as an agent (backlog 64).** The AI button lists OpenCode when `opencode` is installed on the bridge PC. The bridge runs it with `opencode run --format json`, sends the prompt and the game context on stdin, keeps the chat's session with `--session`, reads its reply, its plain progress lines and its `error` events, and runs it in OpenCode's own read-only `plan` mode outside the mentor workspace. A model and its reasoning variant are one name, `provider/model#level`, listed in `agents.opencode.models` in `bridge/config.json`. OpenCode has no tool-off switch, so a translate chat stays on Claude or Grok, and it cannot see screenshots yet, so a look in an OpenCode chat says to pick another agent. Measured on `opencode v2.2.5`; `tests/agents_test.js` parses the recorded stream.
